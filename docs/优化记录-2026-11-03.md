# 2026-11-03 优化记录

## 知识库接口参数校验

`GET /api/knowledge/list` 的 `category` 原来直接参与路径拼接，传入 `..` 或绝对路径可能读取知识库目录外的 Markdown 文件。现改为 FastAPI 枚举参数，只接受 `lecture`、`solutions`、`buglib`、`kp`，非法值返回 HTTP 422。

`GET /api/knowledge/search` 的 `top_k` 限制为 1–100（默认仍为 20）。避免负值、零值导致不一致的结果，以及无上限地返回大量内容。有效分类、非法分类、目录遍历和搜索条数均有回归测试。

## 对话与代码诊断流的可靠性

将共用 SSE 解析器提取到 `frontend/src/sse.js`，保持现有 token、error 和元数据回调协议。

- 支持 LF、CRLF、CR 换行，以及跨网络分块的换行符和中文 UTF-8 字节。
- 支持多行 `data:`，忽略注释和非 JSON 事件；未以空行结束的事件按 SSE 规则丢弃。
- 收到 `done` 或回调异常时取消剩余读取；所有退出路径释放读取器锁。
- 新增 7 项 Node 内置测试，不增加测试依赖；GitHub Actions 在构建前执行 `npm test`。

## 安装与测试隔离

前端锁文件的下载地址由第三方镜像改为官方 npm registry，依赖版本、完整性哈希不变。

后端测试由固定 `/tmp/zhiyu_test.db` 改为每个进程独立的临时目录，避免同时运行测试时互删数据库或共享状态。临时目录退出时自动清理，数据库、WAL 和 SHM 文件一起删除。
