# 汇报指南（答辩 / 课设展示）

> 目标：5-8 分钟讲清「做了什么、为什么这么做、能跑起来」。
> 桌面已经放了两个快捷方式：**智育助教 启动** / **智育助教 停止**，双击即可。

---

## 一、上台前 10 分钟

1. **双击桌面「智育助教 启动」**（或项目根目录 `启动.bat`），等两个黑窗口起来、浏览器自动打开 http://localhost:5173 。
2. 用 `demo_teacher / demo123456` 登录，点右上角「模型设置」填自己的 DeepSeek Key（勾选「记住本机」），**先发一句话确认能回答**。
3. **一个窗口就够**：演示完学生端，点右上角「退出」，再登教师账号即可（5 秒）。
   - 想省这点切换时间，可以再开一个无痕窗口登教师——可选，不是必须。
4. 浏览器按 **F11 全屏**；如果页面样式不对，按 **Ctrl+F5** 强刷。
5. 投影前把缩放调到 125% 左右，字体太小老师看不清。

> 第一次启动要加载模型/建库会慢，务必提前启动，别在台上等。

---

## 二、演示路线（约 6 分钟）

### 1. 学生端（2 分钟）—— 浏览器 A，`demo_student / demo123456`

- **首页**：待办 2 个、最近提交带分数、我薄弱的知识点（按诊断的提示层级累计）
- **作业中心**：点「单链表插入训练」→ 看自己提交的代码、AI 诊断全文、老师评语 88 分
- **去完成**：点一个未完成任务 → 自动跳到「学习助手 · 代码诊断」
  - 贴一段错误代码（比如插入顺序写反），点「开始剖析」
  - 重点讲三件事：**AI 只反问不代码**、回答下方列出**参考知识点**、末尾弹出**诊断标签**（错因/严重度/提示层级）

### 2. 教师端（2 分钟）—— 浏览器 B，`demo_teacher / demo123456`

- **首页**：9 名学生、4 个任务、11 条待批阅、近 14 天提交趋势、班级薄弱知识点
- 点「去批阅 →」→ **班级管理**：任务提交率、错因分布、知识点掌握度、学生进度（未交名单）
- 「查看提交」→ 批阅：**弹窗里能看到学生答案 + AI 诊断全文**，打分 + 评语 + 可退回
- 右上角「导出成绩 CSV」→ 现场用 Excel 打开
- 回学生端刷新：**分数和评语立刻可见**

### 3. 知识库（1 分钟）

- 知识库页：讲义 43 / 题解 16 / Bug 库 30 / **知识点 80 块**
- 点开一个知识点：概念、要点、典型错误、分级练习（三阶提示）
- 说一句：检索结果带 `kp_id`，作业与掌握度都按知识点聚合

### 4. 技术与数据（1 分钟）

- **不泄题三层防线**：Prompt 硬约束 → 三阶提示法 → 知识库内容自净（题解只写思路）
- **可验证**：`py scripts\leak_check.py` 扫描全部历史回复，当前 17 条、0 命中、通过率 100%
- **结构化诊断**：模型末尾输出 JSON，后端剥离后落库，才有错因分布和掌握度
- **工程**：BYOK（使用者自备 key，不烧部署者额度）、ONNX 向量化（不依赖 2GB torch）、pytest 5 个接口测试、GitHub Actions
- **知识点**：20/20 通过校验（`py scripts\check_kp.py`）

## 三、老师可能问的问题

| 问题 | 回答要点 |
|---|---|
| 会不会直接给答案？ | 硬约束 Prompt + 三阶提示 + 泄题检测脚本；历史回复 0 命中 |
| 知识库内容哪来的？ | 20 个知识点自编（参考 OI Wiki/教材结构，不复制正文），另有讲义/题解/Bug 库 |
| 用谁的 API？花谁的钱？ | BYOK：每个使用者在「模型设置」填自己的 key，后端透传、不落库；服务端 key 默认不启用（`ALLOW_SERVER_KEY=0`） |
| 能自动判分吗？ | 目前是「AI 诊断 + 教师打分 + 学生看评语」；在线判题（编译运行）是后续 |
| 和头歌/学习通什么区别？ | 头歌强在判题、学习通强在管理；我们做的是**苏格拉底式引导**，不给完整代码，重点在"教会怎么想" |
| 数据能持久吗？ | 单库 SQLite（`backend/data/app.db`），重启不丢；已做旧库迁移 |
| 多少人能用？ | 一个班几十人没问题；更大并发换 Postgres |

## 四、翻车预案

| 现象 | 处理 |
|---|---|
| 端口被占用 / 启动失败 | 双击「智育助教 停止」，再启动 |
| 页面白屏 / 样式错乱 | Ctrl+F5 强刷；确认地址是 5173 |
| 对话提示"未配置模型密钥" | 「模型设置」填有效 key；检查 DeepSeek 余额 |
| 启动很慢 | 提前 5 分钟开；首次要加载 ONNX 模型 |
| 断网 | 知识库浏览、作业/看板仍可用，只有对话不可用 |
| 演示数据被改乱 | 跑 `cd backend; py scripts\seed_demo.py` 重新生成 |

## 五、结束

- 双击「智育助教 停止」：页面窗口、两个服务窗口、后台进程会一起关掉，不用手动收拾。
- 数据仍在 `backend/data/app.db`，下次启动继续用。
