# 链表（单链表 / 双链表 / 循环链表）

## 核心概念

链表是一组通过指针相互连接的结点序列，每个结点包含「数据域」与「指针域」。与数组相比，链表插入删除 O(1)（已知位置），但随机访问 O(n)，且无随机缓存局部性。

单链表结点结构：`data` + `next`（指向后继）。双链表多一个 `prev`（指向前驱）。循环链表尾结点 `next` 指向头结点。

## 单链表插入的关键顺序

在结点 `p` 之后插入新结点 `q` 的正确顺序是「**先接后链，再改前链**」：

1. `q->next = p->next;`（新结点先接上 p 的后继）
2. `p->next = q;`（再让 p 指向 q）

若顺序颠倒——先 `p->next = q` 再 `q->next = p->next`——此时 `p->next` 已经指向 q 自身，`q->next` 会指向 q，形成自环，原后继结点丢失（断链）。

## 删除结点的顺序

删除 `p` 的后继：直接 `p->next = p->next->next` 即可，但要先保存被删结点指针以便 `free/delete` 释放内存，否则内存泄漏。

## 双链表插入

在 `p` 之后插入 `q` 需维护四条链：`q->prev = p`、`q->next = p->next`、`p->next->prev = q`、`p->next = q`。注意：若 `p->next` 为 NULL（表尾），则 `p->next->prev` 会解引用空指针，需先判空。

## 易错点与考点

- 链表操作前先处理**头结点为空**（空表）与**尾结点**（next 为 NULL）的边界。
- 遍历时若修改链表结构，需保存 `next` 再操作，否则指针失效。
- 删除后未释放内存导致**内存泄漏**；`free` 后指针仍指向原地址导致**悬空指针**。
- 带头结点（哨兵）的链表可统一空表与非空表的处理逻辑，是常用工程实践。
