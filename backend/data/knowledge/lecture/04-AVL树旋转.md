# AVL 树与平衡旋转

## 平衡因子

平衡因子 = 左子树高度 - 右子树高度，AVL 树要求每个结点的平衡因子在 {-1, 0, 1} 内。插入/删除导致失衡时，通过旋转恢复平衡。

## 四种失衡与旋转

以「最低失衡结点」为轴，按其较高子树的形态分为四类：

1. **LL 型**（左左）：左子树比右子树高，且失衡点在左孩子的左子树 → 右单旋（顺时针）。
2. **RR 型**（右右）：右子树高，且失衡点在右孩子的右子树 → 左单旋（逆时针）。
3. **LR 型**（左右）：左子树高，且失衡点在左孩子的右子树 → 先对左孩子左旋，再对失衡结点右旋（双旋）。
4. **RL 型**（右左）：右子树高，且失衡点在右孩子的左子树 → 先对右孩子右旋，再对失衡结点左旋（双旋）。

## 旋转的本质

旋转是**改变局部父子关系**的指针操作：让失衡结点的较高子结点上提为新的根，原根下沉为其子结点，并把旋转过程中「交接」的那个子树挂到正确位置。理解旋转的关键是画图跟踪三条指针的更新，而不是死记四种类型。

## 更新高度

旋转后必须**自底向上**更新各结点高度，并重新计算平衡因子。漏更新高度会导致后续判断继续失衡。

## 易错点与考点

- 分清「失衡结点」与「较高子结点」，选错轴会导致旋转后仍不平衡。
- LR/RL 双旋的本质是先把「之字形」掰成「一字形」再单旋。
- 旋转后返回新的子树根，**忘记把新根接回父结点**是高频错误（树断链/丢失子树）。
- 删除比插入复杂，可能需多次旋转并向上传播。
