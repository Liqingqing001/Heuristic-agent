# 栈与队列

## 栈（Stack）

后进先出（LIFO）。基本操作：`push`（入栈）、`pop`（出栈）、`top`（取栈顶）。栈在函数调用、表达式求值、括号匹配、DFS 递归改写中应用广泛。

用顺序表实现栈时，用 `top` 下标指示栈顶位置。入栈前需判断**栈满**（`top == maxsize-1`），出栈前需判断**栈空**（`top == -1`）。

## 队列（Queue）

先进先出（FIFO）。基本操作：`enqueue`（入队）、`dequeue`（出队）。循环队列用 `front` 与 `rear` 两个指针，为区分队空与队满，通常**牺牲一个存储单元**：队空 `front == rear`，队满 `(rear+1) % maxsize == front`。

## 易错点与考点

- 循环队列的**取模**运算：`rear = (rear + 1) % maxsize`，忘记取模会导致指针越界。
- 出队后仅移动 `front` 而不清空元素不影响正确性，但要理解「逻辑删除」与「物理删除」的区别。
- 栈与队列的**链式实现**中，入队/出队要正确处理头尾指针为 NULL 的边界。
- 判断括号匹配、中缀转后缀、用两个栈实现队列等是经典考题，核心在理解 LIFO/FIFO 的时序。
