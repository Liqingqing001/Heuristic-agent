# 图

## 存储方式

- **邻接矩阵**：O(V^2) 空间，适合稠密图，判断是否有边 O(1)。
- **邻接表**：O(V+E) 空间，适合稀疏图，遍历邻边快。

## 遍历

- **DFS**：递归或显式栈，适合连通性、拓扑、找环。
- **BFS**：队列，适合最短路（无权）、层序遍历。访问过的结点要**及时标记**，否则重复入队导致死循环或指数级开销。

## 最短路径

- **Dijkstra**：单源非负权，贪心 + 优先队列，O((V+E) log V)。
- **Floyd**：多源，三重循环 DP，O(V^3)。

## 拓扑排序

有向无环图（DAG）才有拓扑序。用入度 + 队列：不断取出入度为 0 的结点并删除其出边。**存在环时无法拓扑排序**（取出的结点数 < V）。

## 易错点与考点

- BFS 忘记标记已访问 → 重复入队。
- Dijkstra 要求**非负权**，负权需用 Bellman-Ford 或 SPFA。
- 邻接表遍历时若删除边/结点，迭代器失效问题。
- 判断连通分量、二分图染色、最小生成树（Prim/Kruskal）是常考扩展。
