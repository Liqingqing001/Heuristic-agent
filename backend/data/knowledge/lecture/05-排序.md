# 排序算法

## 分类与复杂度

| 算法 | 平均时间 | 最好 | 最坏 | 空间 | 稳定 |
|---|---|---|---|---|---|
| 冒泡 | O(n^2) | O(n) | O(n^2) | O(1) | 稳定 |
| 插入 | O(n^2) | O(n) | O(n^2) | O(1) | 稳定 |
| 选择 | O(n^2) | O(n^2) | O(n^2) | O(1) | 不稳定 |
| 快排 | O(n log n) | O(n log n) | O(n^2) | O(log n) | 不稳定 |
| 归并 | O(n log n) | O(n log n) | O(n log n) | O(n) | 稳定 |
| 堆排 | O(n log n) | O(n log n) | O(n log n) | O(1) | 不稳定 |

## 快排的分区思想

选 pivot，把小于 pivot 的放左、大于的放右，再递归两侧。核心在 `partition`：常用挖坑法或双指针交换法。**基准选得差（如已有序时选首元素）会退化为 O(n^2)**，可随机选 pivot 或三数取中优化。

## 归并的核心

分治：先递归排序左右两半，再 `merge` 合并两个有序数组。稳定的关键在于合并时「左半边优先」处理相等元素。

## 易错点与考点

- 快排的递归基线（区间只剩 0/1 个元素）忘写会无限递归。
- 快排交换时的下标边界（`i <= j`）写错会导致漏排或死循环。
- 归并合并时越界判断：一个子数组耗尽后，直接把另一个整体拷贝。
- 稳定性：相等元素的相对顺序是否改变，涉及结构体多关键字排序时重要。
- 堆排序需先建堆（自底向上向下调整），再反复「取堆顶 + 调整」。
