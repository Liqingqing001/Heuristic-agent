# 判断链表是否有环（快慢指针）

## 题目

判断单链表是否存在环；若存在，找到环的入口。

## 解题思路（引导，非完整代码）

**判断是否有环：快慢指针**

设置慢指针 `slow` 每次走 1 步、快指针 `fast` 每次走 2 步。若无环，`fast` 会先到达 NULL；若有环，二者必然在环内相遇。

伪代码：

```
slow = head, fast = head
while fast != NULL and fast.next != NULL:
    slow = slow.next
    fast = fast.next.next
    if slow == fast:  // 相遇，有环
        return true
return false
```

**找环入口（Floyd 判圈）**

相遇后，把其中一个指针放回 `head`，两指针都每次走 1 步，再次相遇处即环入口。

## 关键点

- 为什么快慢指针能相遇：快指针相对慢指针每步接近 1 格，终会追上。
- 循环条件要同时判断 `fast` 与 `fast.next`，防止 `fast.next.next` 空指针。
- 相遇点不一定是环入口，需二次同速寻找。
