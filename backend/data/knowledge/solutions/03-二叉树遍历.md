# 二叉树的前/中/后序与层序遍历

## 题目

分别实现二叉树的前序、中序、后序（递归或迭代）与层序遍历。

## 解题思路（引导，非完整代码）

**递归（三种序统一模板）**

访问顺序的差别只在「处理根」的相对位置：

- 前序：先处理根 → 左 → 右
- 中序：左 → 处理根 → 右
- 后序：左 → 右 → 处理根

递归基线：`node == NULL` 时返回。

**迭代**

- 前序：用栈，先压右孩子再压左孩子（出栈顺序左先右后）。
- 中序：沿左链一路入栈，出栈访问后再转向右子树。
- 后序：前序「根右左」的逆序，或加标记栈。

**层序**

用队列 BFS：根入队，循环出队访问，再把左右孩子入队。

## 关键点

- 递归基线（判空）不可省。
- 迭代中序的「入栈直到最左」结构是高频考点。
- 层序用队列而非栈，天然保证同层顺序。
