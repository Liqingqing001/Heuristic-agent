# 反转单链表

## 题目

给定一个单链表的头结点，反转链表并返回新的头结点。

## 解题思路（引导，非完整代码）

**方法一：迭代（三指针）**

核心思想：遍历链表，把每个结点的 `next` 指向它的前驱。需要三个指针——`prev`（已反转部分的新头）、`curr`（当前处理的结点）、`next`（先保存 curr 的原后继，否则改向后就丢了）。

伪代码：

```
prev = NULL
curr = head
while curr != NULL:
    next = curr.next      // 先保存后继，避免断链
    curr.next = prev      // 反转当前结点的指向
    prev = curr           // prev 前移
    curr = next           // curr 前移
return prev               // prev 即新头
```

**方法二：递归**

递归到倒数第二个结点开始回溯，让 `head.next.next = head`、`head.next = NULL`。基线是空表或单结点。

## 关键点

- 迭代法**先保存 next** 再改向，顺序错误会断链。
- 返回的新头是原链表的尾结点。
- 空表 / 单结点需单独处理。
