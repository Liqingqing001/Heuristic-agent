## 概念

单链表由一串**结点**组成，每个结点分两部分：存数据的 `data` 域和存后继地址的 `next` 域。结点在内存里不要求连续，靠 `next` 一个一个串起来，所以链表插入删除只改指针、不搬数据，代价是只能顺序访问。

初学者最容易卡住的不是结点本身，而是「谁指向谁」。链表里通常有三个容易混淆的东西：

- **头指针 `head`**：一个指针变量，指向链表的第一个结点。它是链表的"入口"，丢了它整条链表就找不回来了。
- **头结点**：一个额外加在首元结点之前的哨兵结点，它**不存有效数据**，`next` 指向首元结点。它的作用是让"在第一个位置插入/删除"和"在中间插入/删除"用同一套代码，不用特判。
- **首元结点**：真正存放第一个元素的结点。

用带头结点的链表时，空表判断是 `head->next == NULL`；不用头结点时，空表判断是 `head == NULL`。这两个条件含义完全不同，写混了就会出现"空表时崩溃、非空表时正常"的诡异现象。

## 要点

- `head` 是**指针变量**，头结点是**结点**，二者不是同一个东西。
- 带头结点：空表 `head->next == NULL`；不带头结点：空表 `head == NULL`。
- 头指针不能丢，遍历时用另一个指针 `p = head->next` 往后走，不要直接改 `head`。
- 单链表只能单向走，需要"回头看"的时候要么存前驱，要么改用双链表。

## 典型错误

### 错误 1：把 head 当成第一个数据结点

- 现象：打印链表时第一个元素总是乱码或 0，删除第一个元素后链表直接断掉。
- 原因：带头结点的链表里，`head` 指向的哨兵结点不存有效数据，`head->data` 是未初始化的值；`head` 本身也不该被当作数据结点删除。
- 引导问题：你的链表里，`head->data` 存的是第几个元素？如果它是第 0 个不存数据的结点，遍历应该从哪个指针开始？

### 错误 2：空表判断套用了另一种写法

- 现象：链表为空时程序崩溃；一旦插入第一个元素就一切正常。
- 原因：代码是带头结点的结构，却写成了 `if (head == NULL)`。此时 `head` 本身不为空（它指向哨兵），于是代码认为表非空，去访问 `head->next->data`，解引用了空指针。
- 引导问题：你的 `head` 在空表时到底是不是 NULL？如果它一直指向哨兵结点，那真正表示"没有元素"的是哪个指针？

### 错误 3：遍历时直接移动 head

- 现象：遍历能正常打印，但函数返回后再用这条链表就出问题了，或者第二次遍历什么都没有。
- 原因：`while (head != NULL) head = head->next;` 会把头指针一路推到表尾，原来的入口地址丢失，整条链表泄漏。
- 引导问题：循环结束后 `head` 停在哪里？函数外面还需要用这个头指针吗？那应该用一个什么变量来代替它往后走？

## 分级练习

### 练习 1：判断带头结点单链表是否为空（难度：1）

- 题面：给出一个带头结点的单链表头指针 `head`，写一个函数返回它是否为空表，并说明如果改成不带头结点的链表，条件要怎么写。
- 一阶提示（反问）：空表的时候，"没有元素"这件事体现在哪个指针的取值上？
- 二阶提示（定位到行）：看 `head` 与 `head->next` 这两者，哪一个在空表时才为 NULL？
- 三阶提示（伪代码/类比）：头结点像一个"门卫"，门卫本人在不在不重要，重要的是他身后有没有人——所以要检查的是门卫身后的那个指针。
- 验收点：空表返回真、插入一个元素后返回假；不带头结点的版本条件为 `head == NULL`。

### 练习 2：统计单链表结点个数（难度：2）

- 题面：分别对带头结点和不带头结点的单链表写计数函数，要求不修改原链表。
- 一阶提示（反问）：计数的时候，"当前结点"应该由哪个变量表示？它一开始指向哪里？
- 二阶提示（定位到行）：检查循环条件用的是 `p != NULL` 还是 `p->next != NULL`，以及 `p` 的初值是不是首元结点。
- 三阶提示（伪代码/类比）：像数队伍里的人，先看第一个人是谁（初值），再一个个往后报数（`p = p->next`），报到最后一个人为止。
- 验收点：长度 0、1、5 的链表结果都正确，且函数返回后 `head` 未被改变。

### 练习 3：用头插法建立单链表（难度：3）

- 题面：依次读入 n 个整数，用头插法建成带头结点的单链表，并说明输出顺序为什么和输入顺序相反。
- 一阶提示（反问）：每插入一个新结点，它应该成为链表的第几个元素？
- 二阶提示（定位到行）：插入时先接新结点的 `next`，还是先改 `head->next`？顺序反了会发生什么？
- 三阶提示（伪代码/类比）：像往一摞盘子上放盘子，新盘子永远压在最上面，所以最后放的反而最先拿到。
- 验收点：输入 1 2 3，遍历输出 3 2 1；链表长度为 3，无环、无泄漏。
