## 概念

单链表的插入和删除都只改指针，不动数据，所以时间复杂度是 O(1)——但前提是**已经站在正确的位置上**。找位置本身仍然是 O(n)，这是链表和数组最大的取舍。

插入的难点是顺序。要在结点 `p` 之后插入新结点 `q`，必须**先接后链，再改前链**：

```c
q->next = p->next;   // 1. 新结点先记住 p 原来的后继
p->next = q;         // 2. 再让 p 指向 q
```

第 1 步不能和第 2 步交换。如果先写 `p->next = q`，`p` 原来指向的那个后继地址就被覆盖了，第 2 步再写 `q->next = p->next` 时，`p->next` 已经是 `q` 自己，于是 `q->next = q`，形成自环，原来的后半条链表整体丢失。

删除的难点是**收尾**。删除 `p` 的后继时，除了把 `p->next` 跨过去，还要把被删结点 `free`/`delete` 掉，否则内存泄漏；释放之后原指针变成悬空指针，不能再访问。删除本身还要先判断"有没有后继"，否则对表尾删除会解引用空指针。

## 要点

- 插入固定顺序：`q->next = p->next;` 然后 `p->next = q;`。
- 删除固定顺序：先保存被删结点 `t = p->next;`，再 `p->next = t->next;`，最后 `free(t);`。
- 任何修改指针的操作，先问三件事：空表吗？在表头/表尾吗？释放后还有谁指向它？
- 头结点（哨兵）的价值就在这里：有了它，"在第一个位置插入/删除"不再需要单独写一段代码。

## 典型错误

### 错误 1：插入时两条赋值写反，链表出现自环

- 现象：插入后遍历陷入死循环，或者只能打印出前几个结点；调试器里看到某个结点的 `next` 指向自己。
- 原因：先执行了 `p->next = q`，`p` 原来的后继地址丢失；随后 `q->next = p->next` 读到的是 `q` 本身，于是 `q->next = q`。
- 引导问题：执行完第一条赋值以后，`p->next` 变成了谁？这时你还能找到 `p` 原来的后继吗？

### 错误 2：删除结点只跨指针，没有释放内存

- 现象：程序功能完全正常，但长时间运行内存持续上涨，用 valgrind / AddressSanitizer 报告 definitely lost。
- 原因：`p->next = p->next->next;` 只是把结点从链上摘下来，那块内存仍然被占用，而且再没有任何指针指向它，永久泄漏。
- 引导问题：被摘下来的那个结点，现在还有变量能指向它吗？如果没有，这块内存谁来归还？

### 错误 3：删除表尾或空表时解引用空指针

- 现象：删除最后一个元素时崩溃；删除空表时也崩溃。
- 原因：没有先判断 `p->next` 是否为 NULL 就直接写 `p->next->next`，对 NULL 解引用。
- 引导问题：如果 `p` 已经是最后一个结点，`p->next` 是什么？再对它取 `->next` 会发生什么？

## 分级练习

### 练习 1：在结点 p 之后插入新结点 q（难度：2）

- 题面：给定带头结点的单链表和指向某个结点的指针 `p`，在 `p` 之后插入值为 `x` 的新结点，要求链表其余部分不受影响。
- 一阶提示（反问）：插入完成后，`p` 的后继应该是谁？`q` 的后继又应该是谁？
- 二阶提示（定位到行）：先写哪一条赋值，才能保证 `p` 原来的后继不丢失？试着把两条赋值交换后画一遍指针图。
- 三阶提示（伪代码/类比）：像接力赛交棒——新选手（q）先记住下一棒是谁，上一棒（p）再改指向新选手。
- 验收点：插入后遍历顺序正确，长度加一；`p` 原来的后继仍能从 `q->next` 找到；无自环。

### 练习 2：删除第一个值为 x 的结点（难度：3）

- 题面：在带头结点的单链表中删除第一个数据域等于 `x` 的结点，找不到时不做修改并返回失败标志。
- 一阶提示（反问）：要删除一个结点，你必须同时知道它的哪一个"前驱"信息？遍历时怎么保证手里一直有前驱？
- 二阶提示（定位到行）：循环条件里检查的是 `p->next->data` 还是 `p->data`？删除动作发生的位置在循环内还是循环后？
- 三阶提示（伪代码/类比）：像在队伍里找人，你得站在前一个人旁边看下一个人的脸；找到后让前一个人直接看向下下个人。
- 验收点：删除首元结点、中间结点、表尾结点、找不到 x 四种情况都正确；被删结点已释放；链表不断。

### 练习 3：删除倒数第 k 个结点（难度：4）

- 题面：只遍历一次，删除单链表中倒数第 k 个结点（k 从 1 开始），k 非法时不修改链表。
- 一阶提示（反问）：只走一趟，你怎么知道"现在离结尾还有 k 步"？能不能让两个指针保持固定距离一起走？
- 二阶提示（定位到行）：先让一个指针走 k 步，再让两个指针同时走；循环结束时第二个指针停在哪里？它应该是被删结点的前驱吗？
- 三阶提示（伪代码/类比）：像两个人用一根长度固定的绳子连着走，前面的人撞到终点时，后面的人正好离终点 k 步。
- 验收点：k = 1（删尾）、k = 长度（删首元）、k > 长度（不修改）三种情况都正确；只遍历一次。
