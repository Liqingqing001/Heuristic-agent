## 概念

栈的两个经典应用，本质都是同一件事：**把还没处理完的东西先存起来，等需要时按"最近"的顺序取回**。

**括号匹配**：从左到右扫描，遇到左括号就入栈，遇到右括号就弹出栈顶、看两者是不是同一种括号。为什么非得用栈？因为括号的配对规则要求"后打开的必须先关闭"，这正是后进先出。失败只有三种：遇到右括号时栈已经空了（右括号多余）、弹出的左括号类型不匹配（如 `([)]`）、扫描结束时栈里还剩左括号（左括号多余）。

**表达式求值**：中缀表达式里同时存在优先级和结合性，不能从左往右直接算。两条主流路线：一是**双栈法**（操作数栈 + 运算符栈），边扫描边算，遇到运算符时先把运算符栈里所有优先级不低于它的运算符弹出并计算，再把自己压栈；左括号无条件压栈，遇到右括号就一路弹到左括号为止。二是**先转后缀再求值**：用调度场算法把中缀转成后缀（后缀里没有括号，优先级已经由先后顺序编码），再用一个栈求值——遇数字压栈，遇运算符弹出两个数、算完压回。

后缀求值唯一容易翻车的地方是**操作数顺序**：栈是后进先出，先弹出的是右边的操作数。把这条想清楚，减法和除法就不会算反。

## 要点

- 括号匹配的三类失败：右括号多余、括号类型不匹配、扫描结束栈非空；只检查数量是查不出交错误套的。
- 后缀表达式不需要括号，运算符出现的顺序本身编码了优先级与结合性。
- 后缀求值：`b = pop(); a = pop(); push(a op b);`——先弹出的是右操作数。
- 中缀转后缀：数字直接输出；左括号入栈；右括号弹出到左括号为止（左括号出栈但不输出）；运算符入栈前弹出所有"优先级不低于自己"的栈顶运算符。
- 同级运算符左结合，所以出栈条件用 `>=`；若运算符是右结合的（如幂），才改用 `>`。

## 典型错误

### 错误 1：后缀求值时两个操作数用反

- 现象：加法和乘法结果都对，减法、除法的结果总是反的：`3 4 -` 得到 1 而不是 -1，`8 2 /` 得到 0.25。
- 原因：栈是后进先出，先弹出的是右操作数。代码里写成 `a = pop(); b = pop(); push(a - b);` 就把"被减数"和"减数"、"被除数"和"除数"整个调换了。加减乘里只有减会暴露这个错误，所以常常只错一半。
- 引导问题：`3 4 -` 里 3 和 4 谁先入栈？谁先被弹出？被减数是先入栈的那个，还是先弹出的那个？

### 错误 2：括号匹配只数个数、不检查类型

- 现象：`([)]`、`{(})` 这类交错嵌套的串被判为合法；作业里的测试用例基本都对，换成手写的怪串就错。
- 原因：用两个计数器统计左右括号数量，或者只在遇到右括号时把数量减一。计数器能对上"个数"，但丢掉了"最近一个还没配对的左括号是谁"这个信息，而嵌套结构正是靠这个顺序判定的。
- 引导问题：读到 `)` 的那一刻，你怎么知道该配最近那个 `(` 还是更早的 `[`？这个"最近"的信息你存在哪里？

### 错误 3：中缀转后缀时同级运算符没有弹出

- 现象：`a - b + c` 转成 `a b c + -`，求值结果是 `a - (b + c)`；`a / b * c` 也只是碰巧因为乘除可交换才没那么明显。
- 原因：出栈条件写成了"优先级严格大于自己"（`>`）。同级运算符之间是左结合，先出现的必须先算，所以栈顶运算符优先级**大于等于**当前运算符时都得弹出。
- 引导问题：`a - b + c` 里减号和加号谁先算？如果先算加号，`a` 还会被减号减到吗？

### 错误 4：扫描结束忘了清空运算符栈

- 现象：后缀串比预期短，求值时栈里最后剩下不止一个数；只有带括号或多运算符的表达式出错，简单表达式反而正常。
- 原因：中缀转后缀的最后一步是"把运算符栈里剩余的运算符依次弹出输出"，循环在字符串扫完时就结束了，这一步被漏掉。
- 引导问题：扫描到最后一个字符时，运算符栈里还有东西吗？它们应该出现在后缀串的什么位置？

## 分级练习

### 练习 1：三种括号的匹配检查（难度：2）

- 题面：给定一个只含 `(` `)` `[` `]` `{` `}` 的字符串，判断括号是否合法匹配；不合法时要能说出它属于三类失败中的哪一类。
- 一阶提示（反问）：读到右括号时，你凭什么判断它"配得上"？这个依据存在哪个数据结构里？
- 二阶提示（定位到行）：左括号有没有入栈？栈空时遇到右括号你返回了什么？扫描结束的那个循环后面，还有一行检查栈是否为空的语句吗？
- 三阶提示（伪代码/类比）：像一叠没洗的碗，新碗只能压在最上面，收碗也只能从最上面收；中间抽走一个就说明顺序错了。
- 验收点：`()[]{}`、`{[()]}` 判为合法；`([)]`、`(((`、`]` 判为非法并指出类别；空串判为合法；时间复杂度 O(n)。

### 练习 2：中缀表达式转后缀（难度：3）

- 题面：把含 `+ - * /`、括号和非负整数的中缀表达式转成后缀表达式，相邻操作数之间用一个空格分隔。
- 一阶提示（反问）：两个优先级相同的运算符挨着出现，是左边先算还是右边先算？这个"先"体现在后缀串的哪个位置？
- 二阶提示（定位到行）：处理运算符时你的出栈条件是 `>` 还是 `>=`？遇到左括号是入栈还是直接输出？遇到右括号时弹到左括号为止，左括号本身要不要输出？
- 三阶提示（伪代码/类比）：像排队过安检，新来的人要等前面"级别不低于自己"的人全部通过才轮到自己；左括号是一道闸门，只放行到它为止。
- 验收点：`3+4*2` → `3 4 2 * +`；`(3+4)*2` → `3 4 + 2 *`；`a-b+c` → `a b - c +`；多重嵌套括号与连续运算符的结果正确。

### 练习 3：后缀表达式求值（难度：3）

- 题面：计算一个合法的后缀表达式（含 `+ - * /`、非负整数，除法按整除处理），返回结果；除数为 0 时返回错误标志。
- 一阶提示（反问）：遇到减号时，你要减掉的是"先弹出的数"还是"后弹出的数"？
- 二阶提示（定位到行）：`pop` 两次之后，`a op b` 里的 `a`、`b` 分别对应哪一次弹出？除数为 0 的分支你写了吗？
- 三阶提示（伪代码/类比）：`3 4 -` 读起来是"3 减 4"，但栈先递出的是 4；把第一次弹出的记作 b、第二次弹出的记作 a，式子自然就是 `a - b`。
- 验收点：`3 4 -` 得 -1、`3 4 2 * +` 得 11、`8 2 /` 得 4；结束后栈里恰好剩一个值；除零返回错误而不是崩溃。
