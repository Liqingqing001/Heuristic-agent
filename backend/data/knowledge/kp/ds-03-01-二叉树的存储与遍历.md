## 概念

二叉树是每个结点最多有两个子结点、并且**左右孩子有严格顺序**的树。这个"有序"很关键：只有左孩子的结点和只有右孩子的结点，是两棵不同的树，所有遍历和还原的题目都建立在这条约定上。

存储有两套方案。**顺序存储**把结点按完全二叉树的编号放进数组：从 1 开始编号时，结点 `i` 的左孩子是 `2i`、右孩子是 `2i+1`、双亲是 `i/2`；从 0 开始编号时，左孩子是 `2i+1`、右孩子是 `2i+2`。它对完全二叉树几乎不浪费空间，但对一棵深度为 `h` 的斜树，`n` 个结点要把数组开到 `2^n - 1` 才够。**链式存储**让每个结点存 `lchild`、`data`、`rchild` 三个域，是最常用的形式；`n` 个结点的二叉链表一共有 `n+1` 个空指针域，线索二叉树就是把这些空指针改造成指向前驱、后继的线索，从而在不加栈的情况下完成中序线索遍历。

遍历是一切操作的基础。先序、中序、后序的区别**只在"根"被访问的时机**：先序"根左右"、中序"左根右"、后序"左右根"，左子树永远排在右子树之前；层序则按层自左向右，需要借助队列。递归遍历之所以那么短，是因为系统栈替你记住了"左子树处理完该回到哪个结点、接下来要去右子树"。

## 要点

- 顺序存储 1 基编号：左孩子 `2i`、右孩子 `2i+1`、双亲 `i/2`；0 基编号整体错一位，两套公式不能混用。
- 先序/中序/后序只有"根"的访问位置不同，左右子树的相对顺序永远不变。
- `n` 个结点的二叉链表有 `n+1` 个空指针域。
- 层序遍历用队列：出队一个结点，就把它**非空**的左右孩子依次入队。
- 已知"中序 + 先序"或"中序 + 后序"能唯一确定一棵二叉树；只给"先序 + 后序"不能唯一确定（单孩子结点分不清左右）。

## 典型错误

### 错误 1：顺序存储的下标公式 0 基与 1 基混用

- 现象：打印出来的树结构错乱，有的结点被当成别人的孩子，或者访问到数组里根本没存数据的空位；根结点甚至成了自己的左孩子。
- 原因：数组下标从 0 开始（根在下标 0），公式却照抄了教材的 1 基版本，用 `2*i` 和 `2*i+1` 求孩子，根的孩子被算成下标 0 和 1，等于把根自己当成了孩子。
- 引导问题：你的根结点存在下标 0 还是下标 1？如果根在下标 0，它的左孩子应该在哪个下标？

### 错误 2：中序遍历的两条递归调用写反

- 现象：输出与手算结果正好相反，比如手算 `DBEAC`、程序输出 `CAEBD`；用中序遍历打印二叉排序树，得到的是降序。
- 原因：`inorder` 里先递归了右子树再访问根，等于写成了"右根左"。只盯着"根要放在中间"而没检查两条递归调用的先后，很容易写出这种镜像遍历。
- 引导问题：中序遍历的名字里，"中"指的是根在什么位置？在访问根之前，你递归的是哪一边？

### 错误 3：递归遍历缺少空树基线

- 现象：对空树调用遍历就崩溃；或者在叶子结点上访问 `p->lchild->data`，报空指针。
- 原因：没有把 `if (p == NULL) return;` 放在函数第一行，而是写了 `if (p->lchild != NULL)` 这种局部判断，函数一进来就先取了 `p->data`。
- 引导问题：函数被调用的那一刻，`p` 一定是非空的吗？谁保证这件事？叶子的孩子也会被当作参数传进来时，第一行该做什么？

### 错误 4：层序遍历把空孩子也入队

- 现象：层序输出里混进无意义的数，或者出队时崩溃；个别写法还会在只剩叶子时死循环。
- 原因：入队前没有判断 `p->lchild != NULL`，把 NULL 当成一个元素压进了队列，出队后对它取 `->data` 解引用。
- 引导问题：队列里存的应该是"结点"还是"可能不存在的孩子"？左右孩子为空时，你有没有跳过它们？

## 分级练习

### 练习 1：写出三种遍历序列（难度：2）

- 题面：给定一棵 7 个结点的二叉树（用括号表示法或用图示给出），写出它的先序、中序、后序遍历序列，并说明三者为什么长度相同而顺序不同。
- 一阶提示（反问）：三种遍历访问的结点完全一样，那它们的差别只可能出现在哪里？
- 二阶提示（定位到行）：在你的递归函数里，`visit(p)` 这一行写在两次递归的哪一个位置？
- 三阶提示（伪代码/类比）：把树想成一本分成左右两册的书：先序先读目录再读内容，中序先读左册再读目录，后序是两册都读完才回头补目录。
- 验收点：三个序列都包含全部 7 个结点且不重复；中序序列用于二叉排序树时为升序；与手算结果逐位一致。

### 练习 2：用队列实现层序遍历（难度：3）

- 题面：不用递归，用队列按层自左向右输出二叉树的所有结点，并额外输出每一层的结点个数。
- 一阶提示（反问）：根是第一个被访问的，访问完它之后下一批该轮到谁？这些"下一批"你暂存在哪里？
- 二阶提示（定位到行）：左右孩子是在出队之前入队还是出队之后入队？为空的孩子有没有跳过？你靠什么判断"这一层已经处理完了"？
- 三阶提示（伪代码/类比）：像排队打饭，一个人打完就把他的两个孩子排到队尾，队头永远是当前最早该处理的结点；要分层，就在每轮开始前先记下队列的现有长度。
- 验收点：输出顺序与手算层序一致；各层个数之和等于结点总数；空树输出零个元素且不崩溃。

### 练习 3：求高度与叶子结点数（难度：3）

- 题面：写两个递归函数，分别返回二叉树的高度和叶子结点个数，要求对空树也给出正确结果，且不修改树结构。
- 一阶提示（反问）：整棵树的高度与它左右子树的高度是什么关系？空树的高度你打算定义成 0 还是 -1？
- 二阶提示（定位到行）：`max(左高, 右高)` 后面那个 `+1` 加的是谁？叶子判断看的是 `p == NULL`，还是 `p->lchild == NULL && p->rchild == NULL`？
- 三阶提示（伪代码/类比）：像问左右两个人各自多高、取高的那个再加上自己这一层；数叶子就是看谁没有孩子，再把左右两边的数加起来。
- 验收点：空树高度 0、单结点树高度 1；满二叉树、单支树、空树的叶子数都对；结果与手算一致，树结构未被修改。
