## 概念

遍历序列是二叉树结点的一个线性排列，还原（重构）就是把排列反推回树形。能反推的依据只有两条观察：前序遍历的第一个结点一定是根；中序遍历里，根左边的那一段恰好是左子树的全部结点，右边那一段恰好是右子树。

于是"前序 + 中序"就能唯一确定一棵二叉树：先从前序取根，拿这个值到中序区间里定位，根把中序切成左、右两段，左段长度 k 就是左子树的结点个数；回到前序，紧跟根之后的 k 个结点属于左子树，剩下的属于右子树；左右两段各自递归处理，直到区间为空。

"中序 + 后序"是对称的，根从后序的末尾取。但"前序 + 后序"不行：这两趟都只能确定父子关系，确定不了那个唯一的孩子挂在左边还是右边，所以不同的树会给出完全相同的前序与后序。这就是"为什么必须要中序"的答案——中序提供的是左右划分信息，前序/后序提供的只是"谁是根"。还原的代价是每层递归都要在中序里找一次根，朴素写法 O(n²)，用"值 → 中序下标"的哈希表预处理后可以做到 O(n)。

例如前序 `A B D E C F`、中序 `D B E A C F`，对应的树是：

```text
        A
      /   \
     B     C
    / \     \
   D   E     F
```

## 要点

- 前序（或后序）负责"找根"，中序负责"分左右"；缺了中序，树形不唯一。
- 每层递归只做三件事：定根、切中序、把左子树规模 k 传给前序/后序区间。
- 左子树长度 `k = rootIdx - inL`；前序左段是 `[preL+1, preL+k]`，右段是 `[preL+k+1, preR]`。
- 空子树的判据是区间左端大于右端（`inL > inR`），必须先判空再取根。
- 朴素还原是 O(n²)，瓶颈全在"每层都在中序里找根"；预处理下标表即可降到 O(n)。

## 典型错误

### 错误 1：以为"前序 + 后序"也能唯一还原

- 现象：学生用前序和后序拼出一棵树，和老师给的图不一样，但两趟遍历自己都成立，于是判断题目出错。
- 原因：前序和后序只规定了"谁在谁前面"，没有规定孩子挂在左还是右。只有左孩子的结点和只有右孩子的结点，给出的前序、后序完全相同。
- 引导问题：一棵树是"A 是根、B 是左孩子"，另一棵是"A 是根、B 是右孩子"，它们的前序序列分别是什么？后序呢？

### 错误 2：切中序区间时把根算进了左（或右）子树

- 现象：还原出的树结点总数不对，某个值出现两次或干脆消失；有时递归不收敛，程序栈溢出崩溃。
- 原因：左子树区间应是 `[inL, rootIdx-1]`，长度 `k = rootIdx - inL`。若写成 `[inL, rootIdx]`，根被重复算进左子树，k 多了一，前序区间跟着整体错位一位。
- 引导问题：中序里根自己占的那个位置 `rootIdx`，属于左子树、右子树，还是两边都不属于？

### 错误 3：空区间没有先判空，继续往下递归

- 现象：还原叶子结点时继续递归，读到非法下标（数组越界）或对空指针取 `->left` 而崩溃。
- 原因：只在"能不能找到根"上做了判断，没有在递归入口用 `inL > inR`（或 `preL > preR`）做统一兜底；两个区间长度本来必须相等，只判一边也会漏。
- 引导问题：当 `inL == inR` 时，左子树的区间变成了什么？这个区间的左端和右端，谁大？

## 分级练习

### 练习 1：按前序 + 中序还原这棵二叉树（难度：3）

- 题面：给定结点值互不相同的前序序列 `A B D E C F` 与中序序列 `D B E A C F`，还原这棵二叉树，写出它的后序遍历，并说明每一步是怎么定下根和左右子树的。
- 一阶提示（反问）：前序的第一个字符告诉了你什么？同一个字符在中序里出现的位置，又能把剩下的结点分成哪两堆？
- 二阶提示（定位到行）：把递归写成 `build(preL, preR, inL, inR)`，先在中序 `[inL, inR]` 里找根的位置，再算左子树规模 `k`；检查你把 `k` 用在了 `preL` 的哪一侧、加不加一。
- 三阶提示（伪代码/类比）：像切蛋糕——先找到蜡烛（根）插在哪一刀，左边那块归左子树、右边那块归右子树，两块各自再按同一规则切下去。
- 验收点：还原结果的后序是 `D E B F C A`；把还原出的树重新中序遍历能得到原中序序列；树中恰好 6 个结点且无重复值。

### 练习 2：中序 + 后序还原，并说明唯一性（难度：4）

- 题面：给定中序 `D B E A C F` 和后序 `D E B F C A`，还原这棵二叉树；然后回答：只给前序和后序能否唯一还原？请举一个具体反例。
- 一阶提示（反问）：后序的最后一个结点和前序的第一个结点，哪一个更像"根"？为什么它一定在末尾？
- 二阶提示（定位到行）：后序里根的左子树是一段连续区间，起点是 `postL`，长度同样是 `k`；先算出 `k`，再确认 `postR-1` 落在左段还是右段。
- 三阶提示（伪代码/类比）：中序提供"左右分界"，后序提供"根在末尾"，两者像坐标的两个轴，各给一个维度的信息；只有一个轴，点的位置就画不出来。
- 验收点：还原出的树与前序 `A B D E C F` 完全一致；反例能说清"只有左孩子"和"只有右孩子"的两棵树序列相同，因而无法区分。

### 练习 3：把还原做到 O(n)（难度：4）

- 题面：结点数 n 可达 10^5，要求用前序 + 中序还原整棵树，整体时间复杂度 O(n)，并说明朴素写法为什么会退化到 O(n²)。
- 一阶提示（反问）：每层递归里，"找根在中序中的位置"这一步花了多少时间？这个查找被重复执行了多少次？
- 二阶提示（定位到行）：`build` 里那个从 `inL` 循环到 `inR` 找根的下标循环，可以换成什么结构让单次变成 O(1)？这个结构应该在递归开始之前建好一次。
- 三阶提示（伪代码/类比）：像翻字典前先建索引——把"结点值 → 中序下标"预先存进一张表，之后每次只看一眼。
- 验收点：n = 10^5 的链状最深数据能在 1 秒内出结果；O(n) 版本与朴素版本逐结点比对完全一致。
