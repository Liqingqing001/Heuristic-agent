## 概念

单链表的每个结点只知道自己的后继，**没有指向前驱的指针**，这决定了反转必须"边走边改向"，而不能从后往前改。原地反转的经典做法是维护三个指针：`prev` 指向已经反转好的那一小段的新头，`cur` 指向当前还在原链上的结点，`nxt` 用来暂存 `cur` 的后继。核心顺序是**先保存、再改向、最后前移**——如果先改 `cur->next` 而不事先保存，原链的后半段就没有任何指针指向它，就地丢失。

```c
nxt = cur->next;         // 1. 先存后继，改向之后就找不到它了
cur->next = prev;        // 2. 反转当前这条边
prev = cur; cur = nxt;   // 3. 两个指针整体前移一格
```

循环结束时 `cur` 为 NULL，`prev` 就是新的头结点。

快慢指针是另一条思路：让 `slow` 每次走一步、`fast` 每次走两步，**两者之间的速度差会把"距离差"变成"时间差"**。如果链表有环，`fast` 一定会在环里追上 `slow`；如果无环，`fast` 会先到达 NULL，此时 `slow` 恰好停在中点。同一套骨架只换停止条件，就能求中点、求倒数第 k 个结点、判断回文——这也是它比"先数长度再走"更值得掌握的原因：一趟扫描同时完成两件事。

## 要点

- 反转三件套的固定顺序：存后继 → 改向 → 前移；三条里唯一绝对不能动位置的是"存后继必须在改向之前"。
- `prev` 初始化为 NULL，会让原首元结点自然成为新表尾、`next` 正好为空，不需要额外收尾；这一步漏了就会成环。
- 快慢指针的循环条件写 `fast != NULL && fast->next != NULL`，进了循环体才允许访问 `fast->next->next`。
- 无环时 `fast` 停在 NULL，`slow` 停在中点；长度为偶数时 `slow` 指向后半段的第一个结点。
- 有环时两者必相遇；相遇后把一个指针放回表头，两者同速前进，再次相遇处就是环的入口。

## 典型错误

### 错误 1：先改向后存后继，链表被截断

- 现象：反转后只能看到一两个结点，遍历提前结束；调试器里 `cur->next` 已经变成 `prev`，原来的后继再也找不到。
- 原因：`cur->next = prev;` 覆盖了 `cur` 身上唯一记录后继的字段。此后无论写 `nxt = cur->next` 还是 `cur = cur->next`，读到的都是 `prev`，指针在往回走，链条必然断。
- 引导问题：`cur->next` 是整条链上唯一记住"下一个是谁"的地方，你覆盖它之前，把它存到别的变量里了吗？

### 错误 2：忘记让新表尾的 next 为空，反转后成环

- 现象：正向遍历看起来正常，但打印完最后一个元素后不停下来；释放链表时死循环，或者遍历次数莫名其妙多出好几轮。
- 原因：反转只改了"每条边指向谁"，没有处理"原来最后那条边"。原首元结点变成新表尾，它的 `next` 必须为空；如果 `prev` 起点误写成 `head`，原首元结点的 `next` 还指着第二个结点，而第二个结点此时已指回它，于是成了环。
- 引导问题：反转完成后，原来的第一个结点排在哪里？作为表尾，它的 `next` 现在指着谁、应该指着谁？

### 错误 3：快慢指针循环条件漏判 fast->next

- 现象：奇数长度的链表跑得好，偶数长度的一跑就崩（空指针解引用），报错位置在 `fast = fast->next->next` 这一行。
- 原因：`while (fast != NULL)` 只保证 `fast` 本身非空，而一次走两步需要 `fast->next` 也非空。偶数长度时 `fast` 会正好停在最后一个结点上，它的 `next` 是 NULL，再取一次 `->next` 就越界了。
- 引导问题：`fast` 一步要跨过两格，迈第二步之前，你确认过脚下那第二格是存在的吗？

### 错误 4：找中点时把前后半段的分界点搞错

- 现象：用快慢指针拆链表时，两段长度总是差一，或者干脆变成 1 加 n-1；奇数长度时分成 (2,3) 而要求是 (3,2)。
- 原因：偶数长度时 `slow` 停在 NULL，实际停住的是 `slow` 的上一个结点；拆分时需要的是"前半段的最后一个结点"而不是"后半段的第一个结点"，手里没有它的指针就没法把 `next` 置空。
- 引导问题：掰断一条链需要在哪个结点上动手？这个结点是 `slow` 本身，还是 `slow` 前面那一个？

## 分级练习

### 练习 1：原地反转整条单链表（难度：3）

- 题面：给定不带头结点的单链表头指针 `head`，把整条链表原地反转并返回新的头指针。不允许新建结点、不允许递归、不允许把数据搬来搬去。
- 一阶提示（反问）：你在写 `cur->next = prev` 的那一刻，怎么还能找到 `cur` 原来的后继？
- 二阶提示（定位到行）：检查循环体内三条语句的先后顺序，哪一条必须排在最前？循环结束时你该返回 `cur` 还是 `prev`？
- 三阶提示（伪代码/类比）：像给一列火车调头，每节车厢只记得前面那节——你得先把"下一节是谁"记在小本子上，再让它挂到已经调好方向的车尾上。
- 验收点：长度 0、1、2、5 的链表反转后遍历都正确；新头是原表尾、原首元结点的 `next` 为 NULL；用快慢指针再跑一遍不再相遇（无环）。

### 练习 2：判断有环并返回环的入口（难度：4）

- 题面：不修改链表、不使用哈希表等额外结构，判断单链表是否有环；有环时返回环的入口结点，无环时返回 NULL。
- 一阶提示（反问）：两个人在环形跑道上速度不同，谁先追上谁？如果跑道是直的，快的人到终点时慢的人在哪个位置？
- 二阶提示（定位到行）：先只写"是否相遇"的判断（这一步必须判 `fast` 和 `fast->next`）；相遇之后，把一个指针放回表头、两者都改成一次走一步，再看第二次相等发生在哪。
- 三阶提示（伪代码/类比）：设表头到入口的距离为 a、入口到相遇点为 b、环长为 c。相遇时慢的走了 a+b，快的走了 a+b+k·c；把"快的路程等于慢的两倍"写成等式，解出 a 与 c 的关系。
- 验收点：无环、入口在表头、入口在中间、入口在表尾附近四组用例都正确；额外空间 O(1)；链表结构与数据未被修改。

### 练习 3：用快慢指针找中点并一分为二（难度：3）

- 题面：把单链表从中点拆成前后两段并返回两个头指针；奇数长度时前半段多一个结点；要求只遍历一次。
- 一阶提示（反问）：`fast` 走到 NULL 时，`slow` 停在"前半段的最后一个"还是"后半段的第一个"？两者对拆分有什么影响？
- 二阶提示（定位到行）：拆分靠的是把某个结点的 `next` 置空，这个结点必须是前半段的尾结点；你的循环停下来的那一刻，`slow` 指向它吗？
- 三阶提示（伪代码/类比）：两个人并排走，快的走两格慢的走一格，快的到终点时慢的正处在队伍中央；要把队伍掰成两段，得在中央前一个人手里剪断。
- 验收点：长度 1、2、3、6 拆分后两段长度分别为 (1,0)、(1,1)、(2,1)、(3,3)；两段都不成环；总长度不变。
