# 内存泄漏（Memory Leak）

## 现象

程序内存占用随时间不断增长，长时间运行后变慢甚至 OOM；短期运行可能察觉不到。

## 原因

用 `new`/`malloc` 分配的内存不再使用后，没有用 `delete`/`free` 释放，且指向它的指针丢失（被覆盖或离开作用域），导致内存无法回收。典型：删除链表结点只改链不释放、异常路径提前 return 跳过释放、循环里反复 new 未释放。

## 如何定位

1. 检查每个 `new`/`malloc` 是否都有配对的 `delete`/`free`，尤其所有分支路径。
2. 链表/树删除时，确认被删结点的内存确实被释放，而非只断了指针。
3. 用 valgrind（`--leak-check=full`）或 AddressSanitizer 的 LeakSanitizer 报告泄漏位置。

## 预防

RAII：用智能指针（`std::unique_ptr`/`std::shared_ptr`）、STL 容器自动管理内存；确保所有执行路径都能释放；删除结点时先保存指针再释放。
