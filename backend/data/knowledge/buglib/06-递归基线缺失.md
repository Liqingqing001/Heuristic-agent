# 递归基线缺失（无限递归 / 空指针）

## 现象

递归函数栈溢出（Stack Overflow）、死循环，或在空结点上解引用崩溃。

## 原因

递归函数缺少终止条件（基线），或基线条件写错，导致无法收敛。典型：链表/树遍历时没有判断 `head == NULL` 或 `node == NULL` 就访问 `next`/`left`；快排/归并没有判断区间长度 ≤ 1。

## 如何定位

1. 检查递归函数的第一行是否有基线判断（空指针 / 区间收敛）。
2. 确认递归参数在每次调用中确实向基线方向缩小（如索引收敛、子问题规模减半）。
3. 用调试器观察递归深度是否无界增长。

## 预防

每个递归函数先写基线：链表判空、树判空、排序判区间长度 ≤ 1；基线判断要在访问成员之前；用「基线 + 分解 + 合并」三步法组织递归。
