# AVL 树旋转后仍失衡（新根未接回 / 高度未更新）

## 现象

插入后执行了旋转，但再检查平衡因子仍失衡，或旋转后树的结构被破坏（子树丢失、成环）。

## 原因

两个高频错误：

1. **新根未接回父结点**：旋转函数返回了新的子树根，但调用处没有把这个返回值赋回父结点的指针，导致旧根仍被父结点引用，旋转白做甚至断链。
2. **高度未更新**：旋转改变了子树结构，但没自底向上重算高度/平衡因子，后续判断基于陈旧高度继续误判。

## 如何定位

1. 检查旋转函数是否有返回值，调用处是否 `parent->left/right = rotate(...)` 接回。
2. 检查旋转后是否重新计算了受影响结点的高度。
3. 打印旋转前后整棵树的中序序列与高度，确认结构是否保持 BST 性质。

## 预防

旋转函数统一返回新根，调用处一律接回；旋转后立即更新高度；必要时写递归「返回新根」的插入/删除实现，让接回自然发生。
